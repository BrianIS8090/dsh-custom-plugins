# Настройка после установки на DSH Desktop `0.2.2-rc.3`

Работайте через интерфейс Harness. Это не дамп профиля: не копируйте в репозиторий профиль, ключи, адреса, записи памяти или реальные тестовые данные.

## Плагины с внешними сервисами

- **Codex Image.** Укажите собственный адрес OpenAI-совместимого Images API и сохраните настройки плагина. Добавьте отдельный ключ через его форму (ссылка по умолчанию — `CODEX_IMAGE_API_KEY`). Проверьте подключение без реального изображения, затем запустите пробное задание на несекретных данных. Плагин передаёт выбранному сервису промпты и явно выбранные изображения.
- **Subscription Quota.** Рядом с выбранной моделью откройте **Subscription quota · Настроить**. Укажите HTTPS origin вашего CPA Key Billing без пути, параметров и учётных данных. Введите отдельный ключ CPA, нажмите **Сохранить и проверить**. Проценты обозначают остаток этого ключа, а не расход или квоту текущей модели. Сброс ключа — отдельное действие в плагине.
- **Kimi Cost Meter.** Настройте Kimi Code в **Settings → Models**, затем выберите совместимый маршрут. Дополнительный ключ этому плагину не нужен: плашка использует уже сохранённый credential Kimi Code. Сервис лимитов Kimi не является стабильным публичным API и может менять формат.
- **MCP Panel.** Устанавливается отдельно по [внешнему каталогу](EXTERNAL.md). Настраивайте только нужные подключения; перед передачей диагностики исключите конфигурацию, заголовки и чувствительное содержимое.

## Память, доска и оформление

- Поставьте Mnemon Russian и Guard в указанном в [руководстве](../AGENTS.md) порядке. Фоновые задачи могут создавать отдельные модельные запросы и отправлять фрагменты памяти провайдеру. Проверьте выбранный маршрут и политику обработки данных на синтетической записи.
- Сначала проверьте Russian Kanban в отдельном проекте; при переносе существующей доски используйте её копию. Второй плагин, обслуживающий тот же маршрут и инструменты, выключите до установки.
- Для 7LAMP Harness проверьте обе темы. Reasoning translation и внешние индексы необязательны. Сервис перевода получает развёрнутые фрагменты reasoning; индекс — источник метаданных, а не гарантия безопасности пакета.

Если Host требует `restart-required`, полностью перезапустите Desktop, затем обновите окно. После проверки используйте только необходимые плагины и доступы.

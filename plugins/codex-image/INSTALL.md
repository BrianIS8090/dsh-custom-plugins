# Установка плагина Codex image (GPT Image)

Плагин для DeepSeek Harness **0.2.2 и новее (до 0.3)**. Добавляет генерацию и редактирование изображений моделью `gpt-image` через CLIProxyAPI (или любой другой OpenAI-совместимый Images API).

## Что понадобится

- DeepSeek Harness 0.2.2+ (включая `0.2.2-rc.1` и более новые кандидаты этой серии).
- Адрес своего доверенного OpenAI-совместимого API с поддержкой изображений и отдельный API-ключ для него. Для удалённых подключений используйте HTTPS.

## Установка

1. Клонируйте каталог в постоянную папку.
2. Откройте **Плагины → Добавить плагин → Установить сторонний плагин**.
3. Введите абсолютный путь к `plugins/codex-image`, подтвердите установку и включите bundle. Для локального архива вместо папки можно указать `.tgz`, созданный командой `npm pack` из папки плагина. Не публикуйте этот пакет в npm.
4. Если Harness попросит перезапуск, полностью перезапустите его.

## Настройка

Откройте **Плагины → Codex image (GPT Image)** и пройдите страницу сверху вниз:

1. **Адрес API**: введите свой адрес вместе с `/v1`. Поле изначально пустое; без сохранённого адреса плагин не делает запросов к API.
2. **API-ключ**: вставьте отдельный ключ для этого адреса и нажмите **Сохранить**. Harness хранит его отдельно от настроек под именем `CODEX_IMAGE_API_KEY`, если вы не выбрали другое имя ссылки.
3. **Проверить подключение**: плагин запрашивает список моделей, генерация на это не тратится. Убедитесь, что модель (по умолчанию `gpt-image-2.5`) есть в списке. Если модель называется иначе, впишите её в поле «Модель генерации».
4. Остальное по вкусу: размер, качество, фон, формат, число вариантов, стиль по умолчанию, папка для сохранения.
5. **Сгенерировать пробное изображение**: если картинка появилась, всё работает.

## Как пользоваться

Просто попросите агента в чате:

- «Нарисуй кота-астронавта в стиле акварели»
- «Сделай иконку приложения, минимализм, прозрачный фон, 3 варианта»
- (прикрепив картинку) «Сделай ночь, остальное оставь как есть»

Агент сам вызывает `gpt_image_generate` или `gpt_image_edit`. Картинка показывается в чате и сохраняется в папку `generated-images` рабочей папки сессии.

Если в Harness стоит другой плагин изображений (например `dsh-image-gen`), агент может выбрать его. Тогда либо пишите явно «через gpt_image_generate», либо отключите лишний плагин.

## Удаление

**Плагины → Codex image (GPT Image) → Удалить**. Сохранённый ключ остаётся в хранилище учётных данных Harness. Если он больше не нужен, удалите его там же, где вводили.

## Проблемы

| Сообщение | Что делать |
| --- | --- |
| `No relay base URL is configured` | Укажите свой адрес API и нажмите «Сохранить» |
| `No API key is stored under …` | Введите ключ на странице плагина и нажмите «Сохранить» |
| `The relay rejected the API key (HTTP 401/403)` | Ключ неверный или отозван |
| `Endpoint not found (HTTP 404)` | Проверьте адрес API: он должен заканчиваться на `/v1` |
| `Rate limit or quota exceeded (HTTP 429)` | Закончилась квота или слишком много запросов |
| `No answer from the relay within … s` | Увеличьте таймаут в настройках или поставьте качество «Низкое» |

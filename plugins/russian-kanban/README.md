# Канбан для DeepSeek Harness

Отдельная русскоязычная доска задач на базе `@alpacachen/dsh-kanban` 1.12.0. Сохранены основные функции доски и формат `.dsh-kanban.json`, а модуль Workflow в этот пакет не входит.

## Возможности

- Русские панель, диалоги, фильтры, сообщения и начальные колонки: **К выполнению**, **В работе**, **На проверке**, **Готово**. Существующие названия не изменяются.
- Карточки, сортировка и перенос между колонками, метки, P0/P1/P2, сроки, комментарии, Markdown и изображения.
- Общий файл доски в корне каждой рабочей папки: `.dsh-kanban.json`.
- Автообновление открытой доски каждые 2 секунды и при возвращении на вкладку: действия агента и других окон видны без перезагрузки страницы. При открытой карточке фоновая синхронизация приостанавливается, чтобы не затирать черновики.
- Все 19 `kanban_*` инструментов агента: чтение доски и полной карточки, создание и редактирование задач, перенос, колонки, метки, комментарии и изображения.
- Выбор задачи прямо из чата.

## Выбор задач по `*`

Введите `*` в поле сообщения. Над редактором появятся задачи рабочей папки текущей сессии, сгруппированные по колонкам канбана.

- Продолжайте вводить после `*` название, описание или ID — список отфильтруется.
- **↑ / ↓** выбирают задачу, **Enter** вставляет её, **Esc** закрывает меню.
- Обычный щелчок вставляет одну задачу.
- **Ctrl+Click** или значок выбора добавляет несколько задач; затем нажмите **«Добавить выбранные»**.
- Вставляется ссылка `[kanban:kN]` и название. Полное описание и комментарии агент читает через `kanban_get_card`.
- Выбор только меняет черновик: **ничего не отправляет и не запускает агента**.

Обычный `*` внутри слова и `**жирный текст**` меню не открывают.

## Работа с агентом

Примеры:

```text
Прочитай канбан и предложи порядок выполнения задач.
Создай три карточки с критериями приёмки и перенеси первую в работу.
Прочитай [kanban:k5] и заполни описание результатом проверки.
```

Перед редактированием существующего описания агент читает полную карточку через `kanban_get_card`: `note` заменяется целиком. Удаление карточки необратимо.

## Установка и совместимость

После сборки (см. ниже) выполните из корня каталога плагинов:

```powershell
dsh plugin --profile desktop add ./plugins/russian-kanban
```

Перед включением этого пакета отключите `@alpacachen/dsh-kanban`: оба используют `/api/kanban` и одинаковые `kanban_*` инструменты. Одновременно запускать их нельзя. Старый пакет можно не удалять, а его доска остаётся в рабочей папке.

Плагин рассчитан на **DSH Desktop / Web 0.2.2-rc.3**. После установки обновите страницу; Host при необходимости перезапустите.

## Сборка и проверка

Выполните из каталога этого плагина:

```powershell
pnpm install --frozen-lockfile
pnpm typecheck
pnpm build
pnpm test
```

Проверки включают Host-операции, миграции данных, клиентскую сборку, русскую локаль, выбор по `*`, фильтрацию, вставку нескольких ссылок, автообновление и защиту черновиков от фоновой синхронизации.

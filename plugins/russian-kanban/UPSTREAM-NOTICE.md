# Исходный проект и лицензия

Этот пакет — отдельная русскоязычная модификация только Kanban-части проекта:

- Проект: [`alpacachen/dsh-kanban`](https://github.com/alpacachen/dsh-kanban)
- Исходная версия: **1.12.0**
- Исходный commit: **`0bbcdd199aef134129137c8a476ab4e9d0217313`**
- Лицензия: **MIT**, copyright (c) 2026 alpacachen

Сохранены уведомление об авторских правах и текст лицензии в `LICENSE`.

Изменения: русская локализация, отдельная идентичность `@local/russian-kanban`, новые русские начальные колонки и метки, исключение модуля Workflow, выбор задач из чата по `*` с группировкой по колонкам, множественный выбор и вставка ссылок `[kanban:kN]` без автоматического выполнения.

Upstream-пакет в профиле пользователя не перезаписывается. Формат `.dsh-kanban.json` сохранён для переноса существующих досок. Одновременно запускать обе Host-половины нельзя: общий `/api/kanban` и имена `kanban_*` оставлены для совместимости данных и инструментов.

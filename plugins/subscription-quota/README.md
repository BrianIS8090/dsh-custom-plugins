# Subscription quota для Harness

Локальный плагин для DeepSeek Harness 0.2.2: показывает остаток подписки CLIProxyAPI **внизу поля ввода, непосредственно слева от выбранной модели**. Не заменяет счётчик контекста или другие расширения.

## Использование

1. Нажмите **Subscription quota · Настроить** возле модели.
2. Введите **Billing origin** вашего сервиса в формате `https://billing.example.com` и свой API-ключ CPA Key Billing. Значения origin по умолчанию нет; разрешён только HTTPS origin без пути, query, fragment и учётных данных в URL.
3. Нажмите **Сохранить и проверить**. До успешной настройки обоих полей плагин не выполняет сетевые запросы к billing API.
4. Индикатор показывает остаток / лимит. По нажатию доступны все окна квот, израсходованная сумма, дата обновления лимита и число параллельных запросов.

Данные обновляются раз в минуту, когда страница видима; кнопка **Обновить** запрашивает свежий снимок. Во время сбоя сохраняются последние успешные данные с явным предупреждением. При отклонённом ключе старые цифры не показываются. Если ограничений несколько, в компактном индикаторе показывается наиболее исчерпанное; все остальные — в подробностях. Проценты означают остаток, а не расход.

Плагин показывает квоту введённого ключа независимо от выбранной модели: он не утверждает, что любая модель использует этот ключ. Настройка общая для профиля Harness. Ссылка **Панель статистики** открывает исходный кабинет без передачи ключа в URL.

## Безопасность

- Ключ не входит в исходники, настройки Cordis, URL, localStorage или sessionStorage. Он хранится в штатном хранилище учётных данных Harness под `subscription-quota/api-key` (не обещаем шифрование ОС; формат и права определяет Harness).
- Сохранённый ключ не возвращается браузеру. Поле ввода очищается после сохранения или закрытия окна.
- Ключ отправляется только на HTTPS origin, явно заданный пользователем. Origin хранится локально в credential reference `SUBSCRIPTION_QUOTA_BILLING_ORIGIN`; публичный пакет не задаёт никакого адреса. Перенаправления запрещены. Запросы к API подписки — только GET.
- Локальный API идёт через аутентифицированный owner-only bridge Harness. Изменения требуют специальный заголовок и JSON; если Origin передан, он должен совпадать с Host. Нативный транспорт Harness удаляет Origin после своей проверки доверия, поэтому его отсутствие допускается только внутри уже аутентифицированного bridge. В ответах нет сырых ошибок upstream или секретов.
- Перед заменой рабочего ключа проверяется новый. Удаление — отдельное подтверждаемое действие. Отключение плагина убирает UI и маршруты, но сохраняет ключ; для удаления сначала используйте **Удалить ключ**.

## Установка и отключение

Из корня этого репозитория выполните:

```powershell
dsh plugin --profile desktop add "./plugins/subscription-quota"
```

При необходимости замените `desktop` на имя своего профиля. Также можно выбрать локальный каталог через **Плагины → Установить сторонний плагин**. Менеджер добавит только собственную строку `subscription-quota`. После установки полностью перезапустите Harness, затем сохраните свой API-ключ через кнопку **Subscription quota · Настроить**. Отдельный веб-сервер запускать не нужно.

Отключение: **Плагины → Subscription quota — лимиты CLIProxyAPI**. Отключение убирает UI и маршруты, но сохраняет ключ; для удаления сначала используйте **Удалить ключ**.

## Проверка

```sh
node --check index.js
node --check quota.js
node --check client.js
node --test test/quota.test.mjs
```

Тесты проверяют синтетический формат ответа, обязательную валидацию HTTPS origin, несколько метрик и окон, безлимит, нулевые квоты, обработку ошибок без утечки ключа, безопасную замену/удаление, TTL/single-flight, устаревшие данные, смену ключа во время запроса, защиту локальных мутаций и правильный слот UI.

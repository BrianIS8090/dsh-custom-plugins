# 7LAMP HARNESS

Отключаемый плагин оформления текущего Harness по предоставленному UI-kit 7ЛАМП.

## Что меняется

- Светлая тема: бумажный фон `#f6f7f9`, белые поверхности, индиго `#272446`, красный акцент `#c61938`.
- Тёмная тема: глубокий индиго `#19172c`, поверхности `#272446` / `#322e54`, более светлый красный для читаемого текста.
- Общая шкала скруглений: 12 px для небольших элементов, 22 px для карточек, 32 px для крупных панелей. Геометрию и работу управляющих элементов сохраняет сам Harness.
- Стек интерфейсного шрифта: `Noto Sans, Arial, sans-serif`. Плагин не загружает шрифты из сети: если Noto Sans не установлен, используется Arial. Явно выбранные пользователем шрифты и размеры, шрифты кода и терминала сохраняются.
- В боковой панели — только название **7LAMP HARNESS**, без графического логотипа. На стартовом экране знак также скрыт.
- Основные кнопки: красный фон и белый текст в обоих режимах; наведение — более тёмный красный. Переключатели имеют светлый ползунок, индиго-фон в выключенном состоянии и красный во включённом.
- Фоны пользовательских сообщений, вторичных кнопок, выделения и наведения согласованы с индиго-палитрой.
- Кнопки панели «Старт» имеют сплошную индиго-заливку при наведении; компас светлее и различим на тёмном фоне. Шапки карточек изменённых файлов используют тёмный индиго вместо нейтрального чёрного.
- Для этих встроенных компонентов переопределены шесть непосредственно используемых ступеней `--dsw-static-neutral-*`; это общий слой палитры, а не привязка к хешированным CSS-классам. Типовые цветные иконки файлов/браузера/терминала и семантические цвета diff сохранены.

## Про логотип

Графический знак скрыт в обоих слотах брендинга, чтобы не возвращался встроенный кит Harness. В каталоге плагинов используется нейтральная иконка палитры, а не логотип компании. Сетевых изображений нет.

## Установка и откат

Пакет устанавливается через менеджер плагинов Harness из каталога этого плагина. Он добавляет только строку `sevenlamp-harness`; настройки других плагинов не переписывает.

В разделе «Плагины» найдите **7LAMP HARNESS — фирменное оформление** и отключите плагин или набор. Все слои темы и три замены брендинга принадлежат его контексту: отключение возвращает предыдущее оформление. Изменения действуют для всех сессий текущего профиля.

## Границы

Это оформление Web-интерфейса, в том числе внутри Desktop. Плагин не переименовывает Windows-приложение, ярлыки, нативное меню, поставщика DeepSeek в настройках аккаунта или модели. Системные сообщения, код, подсветка синтаксиса и расширения других авторов не заменяются поиском текста или DOM-патчами.

Используются штатные `theme.overrideTokens` и слоты `sidebar.brand.mark`, `sidebar.brand.name`, `conversation.hero.brand.mark`. Нет `MutationObserver`, таймеров, подмены корневого интерфейса, внешних зависимостей, установочных скриптов и изменений файлов установленного Harness.

## Проверки

```powershell
node --check index.js
node --check client.js
node --test test/*.test.mjs
```

Проверки пакета не заменяют визуальную приёмку. Подключение проверяется через Client Inspect: три слота брендинга и расширенная таблица токенов темы. Для визуальной приёмки проверьте светлый/тёмный режим, стартовый экран, свёрнутую панель и поле ввода.

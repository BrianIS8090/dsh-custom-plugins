# Agent Teams · Выбор модели

Локальный поддерживаемый форк двух MIT-модулей DeepSeek Harness 0.2.2-rc.1.
Оригиналы взяты из npm; лицензии сохранены рядом с модулями. Файлы приложения не меняются.

## Использование

`list_team_models({})` — провайдеры; `{provider}` — модели; `{provider, model}` — точные уровни рассуждения и default.

`spawn_teammate` дополнен `provider`, `model`, `reasoning_effort`. Первые два передаются вместе. Без всех трёх сохраняется штатное наследование последнего запроса Lead. Только effort меняет уровень на родительском маршруте. При смене маршрута без effort применяется default новой модели.

Одинаково работает с `context: fresh` и `fork`. Смена модели fork может потребовать полного пересчёта истории и потерять KV-cache reuse. Это не копирование кеша между провайдерами.

`subagent_with_model` и `subagent_fork_with_model` — обычные субагенты с тем же выбором, без Team roster. Старые инструменты не меняются.

Выбор проходит через `llm.resolveCallConfig` до резервирования имени и передаётся в штатный `subagents.startActivation`. Manager сохраняет маршрут и effort в descriptor и восстанавливает при cold resume. Parent options не меняются. В roster для холодного child неизвестная модель не подменяется моделью Lead.

Это изменение инструментов агента, не новая форма создания агентов в интерфейсе.

## Установка и откат

Устанавливать корень пакета через `plugin_manager install_bundle`. Патч отключает штатные rows `agent-team`, `tool-agent-team`, включает локальные эквиваленты. Отключение всего этого bundle возвращает штатные rows. Установка применяется ко всему профилю и может освободить текущих активных teammates при перезагрузке Team service; их журналы сохраняются.

Точная версия `engines.dsh` намеренно ограничена 0.2.2-rc.1. Порт с 0.2.1-rc.5: vendored-модули пересобраны из npm-пакетов 0.2.2-rc.1; `tool-agent-team` в 0.2.2 не изменился, в `agent-team` принят upstream-переход на handle-регистрацию проекции. Оба узких патча перенесены без изменений. При следующем обновлении Harness снова перепроверить upstream, перенести узкий патч и выполнить тесты.

## Разрешение общих модулей

`runtime-resolver.js` находит `@deepseek-ai` только внутри штатной packaged-установки DSH Desktop: сначала через `process.resourcesPath`, затем через каталог `process.execPath` (включая `Contents/Resources` на macOS) и, наконец, через префикс `app.asar` в `process.argv[1]`. Кандидат принимается только при наличии package manifests обоих Team-модулей. При неудаче ошибка перечисляет проверенные варианты. Установка дублирующих DSH/Cordis-пакетов не требуется и не поддерживается.

## Проверки

`npm test` — наследование и preflight маршрута, discovery, схемы инструментов и portable resolver штатной установки DSH.

Патч домена: единственный новый параметр `request.agentOptions` при штатном создании. Патч инструментов: 3 поля схемы, preflight и передача agentOptions. Без перехватов запросов, monkey patch сервисов или ручных изменений Session events.

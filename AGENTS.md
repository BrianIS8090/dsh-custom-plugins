# Установка и проверка каталога DSH

Цель: воспроизвести публичный набор плагинов на **DeepSeek Harness Desktop `0.2.2-rc.3`**, а не переносить чужой профиль. [README](README.md) — состав; [внешние пакеты](docs/EXTERNAL.md) — точные версии и установка; [настройка](docs/CONFIGURATION.md) — действия после установки.

## Установка

1. Склонируйте репозиторий в постоянную папку. Для проверки используйте отдельный профиль и синтетический workspace; в рабочем профиле заранее сохраните резервную копию данных вне репозитория. Не импортируйте профиль из примеров и не обходите проверки совместимости.
2. Включите только нужные встроенные и npm-пакеты по [списку](docs/EXTERNAL.md). Agent Teams уже входит в DSH; режим включается в меню модели/рассуждений корневой сессии.
3. В **Plugins → Add plugin → Install a third-party plugin** передайте абсолютный путь к каждому нужному каталогу в `plugins/`. Не указывайте корень monorepo: в нём нет устанавливаемого bundle. CLI-формы, если Desktop зарегистрировал команду `dsh`, описаны в [EXTERNAL](docs/EXTERNAL.md).
4. Перед установкой Russian Kanban выполните его [сборку и проверки](plugins/russian-kanban/README.md). Если в другом пакете уже работает доска с `/api/kanban` и инструментами `kanban_*`, остановите прежний пакет перед включением нового; проверяйте перенос и откат на копии доски. Не удаляйте рабочую доску.
5. Для Mnemon следуйте [сборке Mnemon Russian](plugins/mnemon-russian/README.md): сначала соберите и проверьте новый архив, затем установите его и только после этого — [Guard](plugins/mnemon-russian-guard/README.md). Проверьте, что основная сборка одна, а все четыре локализованных Source-модуля обнаружены. Не заменяйте её обычным пакетом из npm без проверки локализации.
6. Если менеджер сообщил `restart-required`, полностью закройте и перезапустите Desktop, затем обновите страницу. Настройте только нужные [учётные данные](docs/CONFIGURATION.md) в интерфейсе. Локальные `link:`-каталоги не перемещайте, пока профиль на них ссылается.

## Критерии

- Нужные bundle активны, без конфликтов строк конфигурации, маршрутов и инструментов. Agent Team Monitor показывает участников и передачу сообщений; War Room открывает отдельное представление совместной работы.
- Running Session Preview `1.3.0` показывает последнее наблюдаемое действие работающей сессии; подсказка раскрывает недавние действия. Тема читаема в светлом и тёмном вариантах.
- Доска работает на синтетических данных и сохраняется после обновления. Codex Image и Subscription Quota до явной настройки не используют личные адреса и ключи автора.

## Проверка перед публикацией

Из чистого checkout используйте Node 24.x (не ниже 24.15) и pnpm 11.9.0. Сначала установите dev-зависимости War Room и Russian Kanban по lockfile (из корня):

```powershell
pnpm --dir plugins/agent-war-room install --frozen-lockfile
pnpm --dir plugins/russian-kanban install --frozen-lockfile
npm test
```

Проверяйте весь подготовленный к отправке снимок и все коммиты отправляемой ветки. Запустите `npm run audit -- <путь-к-чистому-экспорту>` и независимый сканер секретов с редактированием значений в выводе. Отдельно проверьте конечные точки, приватные пути, внешние зависимости и сгенерированные файлы; обычный поиск токенов не ловит все личные адреса. Подтвердите состав артефактов и происхождение стороннего кода. Непроверенная находка блокирует публикацию. Рабочие профили, базы, ключи, персональные адреса, снимки и диагностические файлы не публикуются. Архивы для локальной установки не отправляйте в Git или npm.

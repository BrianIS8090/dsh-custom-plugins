# DeepSeek Harness — каталог плагинов

Самописные плагины и выбранные внешние пакеты для **DeepSeek Harness Desktop `0.2.2-rc.3`**. Это публичный набор исходников и инструкций, а не копия рабочего профиля.

- [Установка и проверка](AGENTS.md)
- [Внешние пакеты](docs/EXTERNAL.md)
- [Настройка после установки](docs/CONFIGURATION.md)

## Самописные плагины

| Плагин | Назначение |
|---|---|
| [Agent Team Monitor](plugins/agent-team-monitor/) | Панель участников Agent Teams, активности и обмена сообщениями. |
| [Agent War Room](plugins/agent-war-room/) | Совместная работа четырёх ролей над одним решением, с журналом и версиями документа. |
| [Russian Kanban](plugins/russian-kanban/) | Русскоязычная доска задач с инструментами агента и выбором карточек из чата. |
| [Running Session Preview](plugins/running-session-preview/) | Последнее наблюдаемое действие работающей сессии и подробности при наведении. |
| [7LAMP Harness](plugins/7lamp-harness/) | Фирменная тема и оформление. |
| [Kimi Cost Meter](plugins/dsh-cost-meter/) | Остатки лимитов Kimi Code. |
| [Subscription Quota](plugins/subscription-quota/) | Квота отдельного ключа CPA Key Billing возле модели. |
| [Codex Image](plugins/codex-image/) | Генерация и редактирование через собственный OpenAI-совместимый Images API. |
| [Mnemon Russian](plugins/mnemon-russian/) | Воспроизводимая русская сборка Mnemon. |
| [Mnemon Russian Guard](plugins/mnemon-russian-guard/) | Восстановление русской локализации на совместимых сборках. |

Внешние пакеты устанавливаются из своих источников; их код не копируется в этот каталог. Разрешения на повторное использование определяют лицензии отдельных проектов. Сторонние уведомления и тексты лицензий сохранены; `UNLICENSED` не является открытой лицензией.

## Границы публикации

Состав ограничен исходниками, проверяемыми сборочными файлами и публичной документацией. Личные конечные точки, ключи, профили, базы, сессии, пользовательские настройки и диагностика в него не входят. Учётные данные настраиваются отдельно в Harness.

# DeepSeek Harness — набор самописных плагинов

Репозиторий содержит исходники девяти локальных проектов для **DeepSeek Harness 0.2.2-rc.1** и инструкции по воспроизведению plugin-слоя текущей конфигурации Desktop.

**Начните с [AGENTS.md](AGENTS.md).** Там приведены порядок установки, сторонние зависимости и проверки результата.

## Состав

| Каталог | Плагин | Статус в исходной конфигурации |
|---|---|---|
| `plugins/agent-team-monitor` | Живая панель Agent Teams | Активен |
| `plugins/agent-team-model-selection` | Выбор модели и reasoning effort для teammates/subagents | Активен |
| `plugins/running-session-preview` | Последнее текстовое сообщение работающей сессии в sidebar | Активен |
| `plugins/7lamp-harness` | Фирменное оформление 7LAMP | Активен |
| `plugins/dsh-cost-meter` | Остатки лимитов Kimi Code | Активен |
| `plugins/subscription-quota` | Квота CLIProxyAPI возле выбранной модели | Активен |
| `plugins/mnemon-russian` | Русская сборка Mnemon | Активен |
| `plugins/mnemon-russian-guard` | Восстановление русской локализации Mnemon после обновлений | Активен |
| `plugins/mneme-russian` | Русская адаптация Mneme | Дополнительный проект; одновременно с Mnemon не устанавливать |

Сторонние пакеты не скопированы в репозиторий: их точные версии и источники перечислены в [docs/EXTERNAL.md](docs/EXTERNAL.md).

## Границы публикации

В репозиторий не входят реальные API-ключи, OAuth-токены, пользовательские профили DSH, записи памяти, сессии, резервные копии, скриншоты переписки, приватные model routes, skills или служебные diagnostic dumps. Настройка учётных данных выполняется каждым пользователем отдельно через штатные интерфейсы DSH.

Лицензии различаются по каталогам. Сохранены upstream MIT/ISC notices. Каталоги с `UNLICENSED` являются source-available, но не предоставляют открытую лицензию на повторное использование собственного кода.
